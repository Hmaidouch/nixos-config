مرجع تخصيص فايرفوكس عبر Nix

دليل شامل لجميع المصطلحات والإعدادات المستخدمة في مجلد mynixos/programs/firefox/، مع أمثلة للتعديل الذاتي.

1. نظرة عامة على الملفات

الملفالوظيفة
default.nixتفعيل فايرفوكس وإعداد البروفايل والخطوط والمظهر عبر وحدة Home Manager.
dotfiles/userChrome.cssتنسيق واجهة المتصفح نفسها (أشرطة الأدوات، التبويبات، شريط العنوان).
dotfiles/userContent.cssتنسيق محتوى صفحات الويب (الخطوط، صفحة التبويب الجديد، شريط التمرير).
الآلية: Home Manager يكتب إعدادات settings في ملف user.js داخل مجلد البروفايل، وهذا الملف يتجاوز ملف prefs.js عند كل إطلاق لفايرفوكس، أي أن إعداداتك تبقى دائمة ولا يمكن تغييرها من واجهة المتصفح. أما ملفات CSS فتُنسَخ إلى مجلد chrome/ داخل البروفايل.

2. إعدادات البروفايل في default.nix

profiles.default = {
  id = 0;
  path = "tagudfjt.default";
  storeId = "305c9bb5";
  settings = { ... };
  userChrome = ./dotfiles/userChrome.css;
  userContent = ./dotfiles/userContent.css;
};
المصطلحالمعنى
programs.firefox.enableتفعيل وحدة فايرفوكس في Home Manager (يثبّت الحزمة وينشئ البروفايل).
profiles.defaultتعريف بروفايل اسمه "default". يمكن تسميته أي اسم، وهو البروفايل الافتراضي (id = 0).
idرقم البروفايل؛ يجب أن يكون 0 للبروفايل الافتراضي ورقماً مميزاً لكل بروفايل إضافي.
pathاسم مجلد البروفايل داخل ~/.config/mozilla/firefox/. هنا استخدمنا المجلد الموجود مسبقاً tagudfjt.default للحفاظ على بياناتك.
storeIdالمعرّف السداسي للبروفايل (ميزة Switchable Profiles في فايرفوكس الحديث). اختياري، وضعناه للحفاظ على القيمة الأصلية.
settingsقائمة التفضيلات (تُكتب في user.js). كل مفتاح يُكتب كـ user_pref("...", value).
userChromeمسار ملف CSS لواجهة المتصفح. يمكن أن يكون نصاً مباشراً داخل default.nix بدل مسار ملف.
userContentمسار ملف CSS لصفحات الويب.

3. إعدادات الخطوط (settings)

المفتاحالقيمة الحاليةالشرح
font.default.x-western"sans-serif"النوع الافتراضي للنصوص: sans-serif أو serif أو monospace.
font.name.sans-serif.x-western"Segoe UI"الخط الأساسي للنصوص العادية (الخطوط اللاتينية/الأوروبية).
font.name.serif.x-western"Segoe UI"الخط الذي تُستخدمه المواقع عندما تطلب خط serif (ترويسة).
font.name.monospace.x-western"Segoe UI"الخط المستخدم للكود والعناصر ذات العرض الثابت.
font.name-list.sans-serif.x-western"Segoe UI, Noto Sans"قائمة بديلة: إذا لم يجد فايرفوكس الخط الأول يجرب التالي. الأفضل لتغطية الرموز الغائبة.
font.name-list.serif.x-western"Segoe UI, Noto Serif"قائمة بديلة لخط serif.
font.name-list.monospace.x-western"Segoe UI, JetBrains Mono"قائمة بديلة للخط الثابت العرض.
font.name.sans-serif.x-arabic"Noto Sans Arabic"الخط للنصوص العربية. استخدمنا Noto لأن حزمة vista-fonts لا تحتوي Segoe UI عربياً.
font.name-list.sans-serif.x-arabic"Segoe UI, Noto Sans Arabic"قائمة بديلة للعربية.
font.size.variable.x-western16حجم خط النصوص العادية بالبكسل.
font.size.fixed.x-western14حجم الخط الثابت العرض (الكود).
font.minimum-size.x-western12الحد الأدنى لأي حجم خط؛ يمنع المواقع من عرض نص صغير جداً.
تلميح: لكل لغة لاحقة خاصة: x-western (اللاتينية)، x-arabic (العربية)، x-hebrew، x-cjk (الصينية/اليابانية/الكورية)...

4. إعدادات المظهر (settings)

المفتاحالقيمةالشرح
ui.systemUsesDarkTheme0فرض الوضع الفاتح. 0 = فاتح، 1 = داكن.
browser.theme.toolbar-theme"light"ألوان أشرطة الأدوات: light / dark / auto.
browser.theme.content-theme"light"ألوان محتوى الصفحات عند استخدام السمة الداكنة/الفاتحة.
browser.display.use_system_colorstrueاستخدام ألوان نظام GTK في عناصر النماذج والأزرار داخل الصفحات.

5. إعدادات الواجهة المدمجة (settings)

المفتاحالقيمةالشرح
browser.compactmode.showtrueإظهار خيار الكثافة "المدمجة" في إعدادات فايرفوكس.
browser.uidensity1كثافة الواجهة: 0 = قياسي، 1 = مدمج، 2 = للمس.
browser.tabs.drawInTitlebartrueسحب شريط التبويبات إلى داخل شريط العنوان (توفير مساحة).

6. ملف userChrome.css (واجهة المتصفح)

هذا الملف يعدّل مظهر فايرفوكس نفسه. يبدأ بمتغيرات CSS تحكم كل شيء:

:root {
  --ff-accent: #7c85f5;        /* اللون المميز (بنفسجي) */
  --ff-accent-soft: rgba(124, 133, 245, 0.18);  /* خلفية لونية ناعمة */
  --ff-bg: #f4f4f8;            /* خلفية أشرطة الأدوات */
  --ff-bg-raised: #ffffff;     /* خلفية العناصر البارزة (شريط العنوان، التبويب النشط) */
  --ff-text: rgba(0, 0, 0, 0.85);    /* لون النص الأساسي */
  --ff-text-dim: rgba(0, 0, 0, 0.5); /* لون النص الخافت */
  --ff-border: rgba(180, 185, 255, 0.25); /* لون الحدود */
  --ff-radius: 10px;           /* استدارة الزوايا */
}
المحدد (Selector)ماذا يفعل
*كل عناصر الواجهة: فرض خط Segoe UI على المتصفح كاملاً.
#navigator-toolbox, #nav-bar, #TabsToolbar, #PersonalToolbarأشرطة الأدوات الرئيسية: خلفية فاتحة بدون حدود.
toolbarكل الأشرطة: لون النص.
#PersonalToolbarشريط العلامات (المفضلة): حجم الخط 11px وارتفاع منخفض.
#PersonalToolbar toolbarbuttonأزرار العلامات داخل الشريط: حشوة صغيرة.
#urlbar-backgroundخلفية شريط العنوان (المكان الذي تكتب فيه الروابط).
#urlbar[focused="true"] #urlbar-backgroundشريط العنوان عند التركيز عليه: حدود ملونة بعلامة تمييز.
.tabbrowser-tab .tab-backgroundخلفية التبويبات: زوايا مستديرة.
.tabbrowser-tab[visuallyselected="true"] .tab-backgroundالتبويب النشط: خلفية بيضاء وحدود.
.tabbrowser-tab[visuallyselected="true"] .tab-labelنص التبويب النشط: داكن.
.tabbrowser-tab .tab-contentنص التبويبات غير النشطة: خافت.
#identity-box, #page-action-buttons toolbarbutton, toolbar #star-buttonأيقونات القفل والنجمة والأزرار بجانب شريط العنوان.
#panel-main-viewالقوائم المنسدلة: خلفية بيضاء ونص داكن.

ملاحظة: !important يمنح القاعدة الأولوية القصوى حتى لا تتغلب عليها أنماط فايرفوكس الداخلية.

7. ملف userContent.css (صفحات الويب)

المصطلح / المحددالشرح
@-moz-document regexp(".*")شرط يطبّق القواعد التالية على كل المواقع.
@-moz-document url(about:newtab), url(about:home)تطبيق القواعد فقط على صفحة التبويب الجديد والصفحة الرئيسية.
* { font-family: ... }فرض Segoe UI على كل النصوص في كل المواقع (مع بديل عربي).
::selectionلون تحديد النص بالماوس.
.search-wrapper .search-handoff-button, .search-wrapper inputشريط البحث في صفحة التبويب الجديد.
.top-site-outer .tileبلاطات المواقع الأكثر زيارة.
scrollbar, scrollbar thumbشريط التمرير ولونه في كل الصفحات.

8. flake.nix — backupFileExtension

home-manager.useGlobalPkgs = true;
home-manager.useUserPackages = true;
home-manager.backupFileExtension = "backup";

عندما تريد Home Manager كتابة ملف موجود مسبقاً (مثل profiles.ini) لا تفشل بل تنقله إلى profiles.ini.backup وتكتب الجديد. هذا ما أنقذ إعداداتك عند أول nrs.

9. المسارات الناتجة بعد التفعيل

~/.config/mozilla/firefox/
├── profiles.ini              ← ملف البروفايلات (يديره Home Manager)
└── tagudfjt.default/         ← بروفايلك (بياناتك الحقيقية)
    ├── user.js               ← إعداداتك من settings (يتجاوز prefs.js)
    ├── chrome/
    │   ├── userChrome.css    ← واجهة المتصفح
    │   └── userContent.css   ← صفحات الويب
    └── ...                   ← العلامات، كلمات المرور، الإضافات

10. أمثلة عملية للتعديل بنفسك

أ) تغيير حجم خط شريط العلامات

في userChrome.css عدّل الرقم 11px:

#PersonalToolbar { font-size: 12px !important; }

ب) تغيير اللون المميز لكل شيء

في userChrome.css و userContent.css غيّر المتغير:

--ff-accent: #ff5c5c;   /* أحمر مثلاً */

ج) تفعيل الوضع الداكن

في default.nix داخل settings:

"ui.systemUsesDarkTheme" = 1;
"browser.theme.toolbar-theme" = "dark";
"browser.theme.content-theme" = "dark";

د) تكبير/تصغير خط صفحات الويب

"font.size.variable.x-western" = 18;  /* أكبر */

هـ) إخفاء شريط التبويبات مع إبقائه ظاهراً عند التمرير

#TabsToolbar { visibility: collapse !important; margin-bottom: 28px !important; }

و) تغيير لون التبويب النشط

.tabbrowser-tab[visuallyselected="true"] .tab-background {
  background: #eef2ff !important;
}

11. خطوات التفعيل والتجريب

  1. عدّل الملفات ثم نفّذ nrs (الاسم المستعار لـ nixos-rebuild switch --flake .#benattia).
  2. أغلق فايرفوكس تماماً وأعد فتحه حتى تُطبَّق التغييرات.
  3. يمكنك فتح about:config في فايرفوكس للبحث عن أي إعداد قبل إضافته إلى Nix.
قاعدة ذهبية: أي إعداد تريده "دائماً" ضعه في default.nix (settings) ليبقى محمياً من التغيير، وأي تنسيق بصري ضعه في ملفات CSS.
